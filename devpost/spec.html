Solo Leveling-Style Life App
Technical Spec

How it works, in plain language

A website that acts like a phone app (a Progressive Web App). You open a link on your phone, tap Add to Home Screen, and it opens full-screen with its own icon.

It is plain HTML/CSS/JavaScript for the screens, a canvas for the fire and army, and the phone's own storage as memory. No server, no accounts. Vercel just keeps the files at a web link, updated each time you push to GitHub.

Later, Capacitor can wrap the same files into a real Android app in Android Studio.

The big picture

Files travel from GitHub, to Vercel, to your phone. After that everything happens on the phone.

Data model

{
  profile:  { dob, lifespanYears, setupDone },
  goal:     { id, name },
  quests:   [ { id, name, deadline:"21:00", priority:1-3, penalty, createdOn, startsOn } ],
  days:     { "YYYY-MM-DD": { done:[questId], checkedIn } },
  coins, xp, level,
  army:     [ { id, catalogId, name } ],
  settings: { accent, muted },
  penalty:  null | { questId, date },     // kept so reloading can't escape the lock
  proofs:   [ { id, date, questId, hasPhoto } ]
}

Saved in localStorage key lifeApp.v1. Photos are blobs in IndexedDB. On reopen everything is restored.

If something breaks

Sound blocked"Tap to begin" screen unlocks it; mute toggle in Settings
Camera won't openType "I did it" and hold 5 seconds
Storage clearedFirst-use flow again; reset in Demo tools
Deadline passes while closedLocks on next open (a web app can't run in the background)

Where it runs and how to try it

Computer: npx serve ., open localhost in phone-size mode.
Phone: open the Vercel link, Add to Home Screen.
Demo video: screen-record the phone. Demo tools in Settings makes a deadline due in 1 minute.
Submission: demo video + public GitHub repo. The Vercel link is a bonus.

Simplified on purpose

  • Device-only storage, no accounts
  • Synthesized sounds, no audio files
  • Ambient Battleground, no combat
  • Three active quests in total (enforces max 3 a day)
  • No background notifications (Capacitor adds them later)
